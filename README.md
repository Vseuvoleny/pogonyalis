# Pogonyalis Turborepo Template

Monorepo template for:
- Vue 3 app (`apps/web`)
- NestJS API (`apps/api`)
- React Native app (`apps/mobile`)
- Shared package (`packages/ui`)

## Quick start

1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Run development mode:
   ```bash
   pnpm dev
   ```

## Apps

- `apps/web` — Vue 3 + Vite
- `apps/api` — NestJS REST API
- `apps/mobile` — React Native (Expo)
- `packages/ui` — shared TypeScript package
